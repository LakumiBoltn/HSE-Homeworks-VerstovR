# Автоматизированный мониторинг и реагирование на угрозы

## Описание проекта
Данный проект представляет собой инструмент для автоматизированного мониторинга безопасности, анализа угроз и имитации реагирования. Система собирает данные из нескольких источников (API VirusTotal, API Vulners и логи безопасности), анализирует их на предмет угроз, выполняет имитацию реагирования (блокировка IP, уведомления) и формирует отчет с визуализацией результатов.

## Функциональность
- **Сбор данных** из API VirusTotal, API Vulners и файлов логов
- **Анализ угроз** с выявлением подозрительных IP, критических уязвимостей (CVSS > 7.0), атак типа brute-force и других инцидентов
- **Реагирование** с имитацией блокировки IP и отправкой уведомлений
- **Формирование отчетов** в форматах JSON и CSV
- **Визуализация** результатов в виде графиков (PNG)

## Используемые технологии
- Python 3.8+
- requests - для работы с API
- pandas - для анализа данных
- matplotlib / seaborn - для визуализации
- json - для работы с данными
